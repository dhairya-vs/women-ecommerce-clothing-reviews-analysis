## Project Overview
This project cleans and explores customer reviews of women's clothing using Python. It covers missing values, duplicate records, data types, numeric validation, outlier screening, eight visualizations, and a concise findings report.

## Dataset
The original CSV is included in `dataset/Womens Clothing E-Commerce Reviews.csv`.

Source: [Women's E-Commerce Clothing Reviews on Kaggle](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews)

## Repository Contents
- `dataset/` — original dataset and cleaned CSV generated by the analysis
- `notebooks/Womens_Clothing_Reviews_Analysis.ipynb` — step-by-step analysis notebook
- `src/analyze_reviews.py` — reproducible cleaning and visualization script
- `graphs/` — eight visualizations
- `reports/data_cleaning_log.md` — cleaning decisions and outlier checks
- `reports/insights_report.md` — key findings and limitations
- `requirements.txt` — Python dependencies

## Run the Analysis
From the repository's root directory, install the dependencies:

```bash
pip install -r requirements.txt
python src/analyze_reviews.py
```

The script reads the included CSV, writes `dataset/cleaned_womens_clothing_reviews.csv`, refreshes the charts in `graphs/`, and updates the reports in `reports/`.

## Key Findings
- Average rating: **4.20/5**
- **77.5%** of reviews have a rating of 4 or 5
- **82.2%** of reviews recommend the product

These results describe this dataset only. They should not be treated as causal findings or as representative of all shoppers.
