# Visualizations

This folder contains eight charts generated by the analysis script:

1. Customer rating distribution
2. Recommended vs. not recommended
3. Average rating by department
4. Top-rated clothing classes with at least 30 reviews
5. Customer age distribution
6. Positive feedback count distribution
7. Review length by rating
8. Most frequent review words

Run `python src/analyze_reviews.py` from the repository root to regenerate the charts.
